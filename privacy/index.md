# プライバシーポリシー

対象のアプリ: なぞっておぼえる ひらがな・カタカナ/なぞっておぼえる かんじ1年〜6年(以下「本アプリ」)

## 1. 集める情報

本アプリは、利用者の情報を集めません。名前・メールアドレス・位置情報・写真・連絡先などを求めることはなく、端末の識別子も使いません。

## 2. 通信

本アプリはインターネットに接続しません。広告、利用状況の解析、外部サービスへの送信の仕組みを組み込んでいません。

## 3. 端末の中に保存する情報

練習の記録(なぞり終えた文字など)と設定(読み上げの声など)を、その端末の中だけに保存します。外部には送りません。本アプリを削除すると、これらの記録も消えます。

## 4. 端末の機能へのアクセス

カメラ・マイク・位置情報・写真・連絡先などへのアクセスは求めません。

## 5. 第三者への提供

集める情報がないため、第三者に提供する情報もありません。

## 6. お子さまの利用について

本アプリは、お子さまが使うことを想定しています。上のとおり情報を集めず、通信もしません。

## 7. 改定

このポリシーを変えるときは、このページでお知らせします。

## 8. お問い合わせのときに扱う情報

アプリの外(このサイト)には、2つの問い合わせ先があります。**どちらもアプリからは開きません**(本アプリに外部へのリンクはありません)。

- **問い合わせフォーム(GitHub)** [https://github.com/nazotte/nazotte.github.io/issues/new/choose](https://github.com/nazotte/nazotte.github.io/issues/new/choose) — GitHub 社のサービスです。**書いた内容と GitHub のアカウント名は公開されます**。
  GitHub の扱いは同社のプライバシーポリシーによります。公開したくないことはメールへお願いします
